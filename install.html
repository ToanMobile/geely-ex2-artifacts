Trình duyệt bảo mật sẽ chặn kết nối trực tiếp đến IP xe nội bộ (http://...). Để cài tự động không dây:
  • Dùng app Phone Connect trên điện thoại để điều khiển và cài đặt.
  • Hoặc mở trang này bằng địa chỉ IP nội bộ HTTP (ví dụ: http://192.168.x.x:8899).
  • Hoặc dùng lệnh ADB ở mục Lệnh cài đặt thủ công (ADB) bên dưới.

💡 Hướng dẫn kết nối & Lệnh cài đặt thủ công

1. Bật Wi-Fi xe: Đảm bảo điện thoại và màn hình xe đang bắt chung một mạng Wi-Fi (hoặc điện thoại bắt Wi-Fi do xe phát ra 192.168.43.1).

2. Bật ADB trên xe: Mở Cài đặt xe ➔ Giới thiệu ➔ Bấm 7 lần vào Số phiên bản (Build Number) để bật chế độ Nhà phát triển.

3. Lệnh chạy nhanh qua ADB (nếu dùng máy tính/Termux):

adb connect 192.168.1.100:5555 && adb install -r CarConnect.apk

HƯỚNG DẪN CÀI ĐẶT 4 BƯỚC (DỄ LÀM)
1
Bấm tải về & Chọn "Vẫn tải xuống"
Nếu trình duyệt cảnh báo "Tệp này có thể gây hại...", hãy an tâm chọn "Vẫn tải xuống" (Download anyway). Đây là cảnh báo tiêu chuẩn của Android cho mọi file APK ngoài Google Play.
2
Mở file sau khi tải xong
Vuốt thanh thông báo trên đỉnh màn hình xuống và bấm vào thông báo PhoneConnect.apk - Tải xuống hoàn tất để mở.
3
Cho phép cài đặt từ nguồn này
Nếu máy báo "Không được phép cài đặt ứng dụng không rõ nguồn gốc" ➔ Bấm Cài đặt (Settings) ➔ Gạt bật công tắc "Cho phép từ nguồn này" ➔ Bấm nút Quay lại rồi chọn Cài đặt.
4
Vượt cảnh báo Play Protect (Nếu có)
Nếu Google Play Protect hiện màn hình cảnh báo "Bị chặn bởi Play Protect" ➔ Bấm vào dòng "Chi tiết khác" (More details) ➔ Chọn "Vẫn cài đặt" (Install anyway).
🛠️ Sự cố thường gặp: Không mở được file / File bị đổi đuôi .zip, .bin
1. File tải về bị đổi tên thành .zip hoặc .bin (Máy Xiaomi, Samsung, UC Browser):
Mở ứng dụng File của bạn (Quản lý tệp) trên điện thoại ➔ Vào thư mục Tải về (Download) ➔ Nhấn giữ vào file ➔ Chọn Đổi tên (Rename) ➔ Xoá đuôi .zip hoặc .bin sửa thành .apk (VD: PhoneConnect.apk) ➔ Bấm vào file để cài đặt.
2. Máy Samsung One UI 6+ báo "Bị chặn bởi Bộ lọc bảo mật tự động":
Vào Cài đặt điện thoại ➔ Bảo mật và quyền riêng tư ➔ Bộ lọc bảo mật tự động (Auto Blocker) ➔ Gạt sang TẮT, sau đó quay lại bấm cài file.
3. Máy Xiaomi / Redmi / POCO đếm ngược 10 giây:
Đánh dấu tích vào ô "Tôi nhận thức được các rủi ro có thể xảy ra..." ➔ Chờ hết 10 giây và bấm nút OK.
